# Microphone Detector

As vezes quando estamos em reuniao no teams deixamos o microfone aberto, esquecido, quando descobrimos as pessoas ja
ouviram nossa conversa, essa aplicaçao colocar bordas verdes no canto da tela para mostrar que microfone esta aberto.


OBS: Ate o momento esta versao funciona somente em Linux (Mint e Ubuntu)

### Instalar LIBs
```
sudo apt-get install libx11-dev libxfixes-dev libxext-dev
sudo apt-get install libasound-dev portaudio19-dev


```
